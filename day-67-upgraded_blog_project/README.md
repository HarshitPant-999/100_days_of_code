Build a RESTful Blog. GET/POST/PATCH/DELETE.



A blog that fatches our Data from Database using SQLAlchemy. Able to create a new blog with 
flask_wtf's PostForm. and Edit it as well.

used Flask for backend Bootstrap for WebDesgin, flask_sqlalchemy's SQLAlchemy for 
storing/fetching/editing the data used sqlitebrowser for the Data Storage,
flask_ckeditor's CKEditor for detailed input Blog for smooth typing Interface & Python's datetime.

Also i used Linux's curl command for testing my REST routing instead of POSTMAN.
